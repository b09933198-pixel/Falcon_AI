# Falcon AI Reference Datasets

This directory contains official numerical validation datasets.

These datasets are NOT generated by Falcon AI.

They are used only to verify that Falcon AI produces results identical to official references.

--------------------------------------------------

Structure

datasets/
    Raw reference datasets

expected/
    Expected numerical outputs

--------------------------------------------------

Rules

1. Never modify a dataset manually.

2. Always keep the original source.

3. Every dataset must include its reference source.

4. Reference validation must be reproducible.

--------------------------------------------------
