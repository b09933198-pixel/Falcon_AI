# Purpose

This document defines the stable foundation of Falcon AI.

Any architectural change after this point must be documented through a new ADR.

---

# Project Identity

Falcon AI

Intelligent Trading Analysis System (ITAS)

Falcon AI is a professional market analysis platform.

It is NOT an automated trading bot.

Its purpose is to assist human decision making through explainable analysis.

- Evidence over Assumption
- Architecture before Features
- Explainability first
- One Responsibility per Module
- Test before Trust
