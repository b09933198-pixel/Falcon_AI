# DEVELOPMENT RULES

Rule 1

Falcon_AI is NOT a trading bot.

---

Rule 2

Every module must have Unit Tests.

---

Rule 3

Every indicator must be validated against a reference implementation.

---

Rule 4

No code without documentation.

---

Rule 5

No feature is considered complete until:

- Code
- Test
- Documentation

are all finished.

---

Rule 6

Quality has priority over development speed.
Rule 7

Every mathematical model must be verified against an official or trusted reference before it is considered complete.

No approximation is accepted without validation.
